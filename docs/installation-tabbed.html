🚀 CRANE Installation Guide

Step-by-step setup for Linux, macOS, and Windows

Before you start: Make sure you have Docker installed and at least 5 GB of disk space. See Verify Prerequisites below.
1

Install Docker

Install Docker Engine and Docker Compose plugin on Ubuntu/Debian:

Terminal
sudo apt update sudo apt install -y docker.io docker-compose-plugin

Then start Docker and add your user to the docker group:

sudo systemctl start docker sudo usermod -aG docker $USER newgrp docker

Verify it works:

docker run hello-world

You should see a "Hello from Docker!" message.

Download and install Docker Desktop for macOS:

  1. Go to Docker Desktop for Mac
  2. Download the version for your chip:
    • Apple Silicon (M1/M2/M3): ARM64 version
    • Intel Macs: Intel x86_64 version
  3. Double-click the downloaded .dmg file
  4. Drag Docker.app to the Applications folder

Start Docker Desktop from Applications folder. You'll see a Docker icon in the top menu bar when it's running.

Verify it works by opening Terminal and running:

docker run hello-world

Install Docker Desktop for Windows:

  1. Go to Docker Desktop for Windows
  2. Click Download for Windows
  3. Run the installer and follow the prompts
  4. When asked about WSL 2: Select "WSL 2 backend" (recommended)
  5. Restart your computer when prompted

After restart, open PowerShell and verify it works:

docker run hello-world
2

Download CRANE

Clone the repository using Git:

Terminal
git clone https://github.com/cra-norm-engine/crane.git cd crane

Or download as ZIP if you don't have Git:

wget https://github.com/cra-norm-engine/crane/archive/refs/heads/main.zip unzip main.zip cd crane-main

3

Configure Environment (.env)

Copy the example configuration:

Terminal
cp .env.example .env

Generate two secure random values:

openssl rand -hex 32 openssl rand -hex 32

Edit .env with nano:

nano .env

Find and update these lines:

POSTGRES_PASSWORD=paste_first_generated_value_here BACKEND_SECRET_KEY=paste_second_generated_value_here

Save with Ctrl+O, then Ctrl+X to exit.

4

Start CRANE

Start all services:

Terminal
docker compose up -d

Monitor the startup (first run takes 2-5 minutes):

docker compose logs -f backend

Wait until you see messages about the app being ready. Then press Ctrl+C to stop viewing logs.

Verify Prerequisites (Before Starting)

Check Docker is installed and running:

docker info

Should print Docker info without errors.

Check Docker Compose:

docker compose version

Should print v2.x.x

Check ports are free:

ss -tlnp | grep -E ':(5173|8000|5432)' || echo "All ports free!"

Check disk space:

df -h / | tail -1

You need at least 5 GB free (check the "Avail" column).

🔧 Troubleshooting

❌ "Cannot connect to Docker daemon"

Error: error during connect: this error may indicate the docker daemon is not running

Start Docker:

sudo systemctl start docker

Open Docker.app from the Applications folder and wait for the Docker menu icon to appear in the top-right corner.

Open Docker Desktop from the Start Menu and wait for it to fully load (it may take a minute).

❌ Port already in use

Error: bind: address already in use

Find what's using port 8000:

sudo lsof -i :8000

Stop that service, or change the port in .env:

nano .env # Change: BACKEND_PORT=8001 # Change: FRONTEND_PORT=5174

Check the logs:

docker compose logs backend docker compose logs postgres

Restart everything:

docker compose down docker compose up -d

❌ Slow startup (>5 minutes)

First run is taking a very long time

This is normal! The vulnerability database is downloading (~200 MB). Check progress:

docker compose logs backend | grep -i trivy

Just wait. Subsequent startups will be much faster.

docker compose ps

You should see frontend, backend, and postgres all showing "running".
