Getting Started

Installation Guide

Step-by-step installation for Linux, macOS, and Windows. Click your OS at each step.

1Install Docker

Install Docker Engine and Docker Compose plugin (Ubuntu/Debian):

sudo apt update
sudo apt install -y docker.io docker-compose-plugin

Start Docker and add your user to the docker group:

sudo systemctl start docker
sudo usermod -aG docker $USER
newgrp docker

Verify it works:

docker run hello-world

Download and install Docker Desktop for macOS:

  1. Go to Docker Desktop for Mac
  2. Download for your chip:
    • Apple Silicon (M1/M2/M3): ARM64 version
    • Intel Macs: Intel x86_64 version
  3. Double-click the .dmg and drag Docker.app to Applications

Start Docker Desktop from Applications. You'll see a Docker icon in the top menu when it's running.

Verify it works:

docker run hello-world

Install Docker Desktop for Windows:

  1. Go to Docker Desktop for Windows
  2. Click Download for Windows
  3. Run the installer and follow the prompts
  4. When asked about WSL 2, select WSL 2 backend (recommended)
  5. Restart your computer

After restart, open PowerShell and verify:

docker run hello-world

2Clone CRANE

git clone https://github.com/cra-norm-engine/crane.git
cd crane

Or download as ZIP:

wget https://github.com/cra-norm-engine/crane/archive/refs/heads/main.zip
unzip main.zip
cd crane-main
git clone https://github.com/cra-norm-engine/crane.git
cd crane

Or download as ZIP:

curl -L https://github.com/cra-norm-engine/crane/archive/refs/heads/main.zip -o crane.zip
unzip crane.zip
cd crane-main

Option A: Using Git

git clone https://github.com/cra-norm-engine/crane.git
cd crane

Option B: Using PowerShell (no Git needed)

Invoke-WebRequest -Uri "https://github.com/cra-norm-engine/crane/archive/refs/heads/main.zip" -OutFile "crane.zip"
Expand-Archive -Path "crane.zip" -DestinationPath "."
cd crane-main

3Configure .env

Copy the example configuration:

cp .env.example .env

Generate two secure random values:

openssl rand -hex 32
openssl rand -hex 32

Edit .env and set these two values:

nano .env

Update these lines with your generated values:

POSTGRES_PASSWORD=<first_generated_value>
BACKEND_SECRET_KEY=<second_generated_value>

Save with Ctrl+O, then Ctrl+X.

Save (Ctrl+S) and close.

4Start CRANE

Start all services:

docker compose up -d

Monitor startup (first run takes 2-5 minutes):

docker compose logs -f backend

Press Ctrl+C to stop viewing logs.
