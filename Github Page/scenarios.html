Using CRANE

Real-World Scenarios

The same platform fits very different teams. These four worked examples show how CRANE's concepts come together end to end — from a single startup product to a consultant running five client programmes at once.

Industrial IoT manufacturer

A manufacturer of connected sensors deployed in factories across the EU needs to demonstrate CRA compliance before placing products on the market.

With CRANE, they:

  • Register each sensor model as a product with its hardware and firmware versions.
  • Upload CycloneDX SBOMs per firmware release — CRANE scores quality and validates CRA requirements.
  • Run vulnerability scans via Trivy and OSV; EPSS scores prioritise which CVEs to fix first.
  • Configure a release gate requiring a passed risk assessment, pentest report and SBOM before any firmware ships.
  • Define a support period per product line with automated end-of-support alerts to customers.
  • Export a complete audit package when the Notified Body requests evidence.

Small IoT startup

A 10-person startup ships a smart energy monitor for residential use. They have no dedicated compliance team, and the CRA is their first regulatory challenge.

With CRANE, they:

  • Set up the product registry in under an hour using Docker Compose — no infrastructure expertise needed.
  • Upload their first SBOM and immediately see which open-source components carry known CVEs.
  • Use the CRA Annex I matrix to understand which obligations apply and track progress against each one.
  • Classify their cloud backend with the Article 3(2) wizard — determine it is in scope and document the rationale.
  • Publish a CVD policy so security researchers know how to report vulnerabilities responsibly.
  • When a critical CVE hits a dependency, log the report, patch it, issue a security update, and keep a full audit trail — all in one place.
  • Download the technical documentation needed for internal conformity assessment and CE marking.

CRA compliance consultant

A consultant runs CRA programmes for five SME clients simultaneously. Each client needs their own compliant product registry and evidence trail.

With CRANE, they:

  • Deploy one self-hosted CRANE instance per client — fully isolated data, no cross-contamination.
  • Use role-based access control to give each client's team read access while retaining admin control.
  • Assess remote processing elements against Article 3(2) using the built-in DIGITALEUROPE I1/I3/I5/I6 wizard.
  • Export the complete dataset at project close — the client takes ownership with no vendor lock-in.
  • Use test-data fixtures to demonstrate the tool during CRA awareness workshops.
  • Pay no per-seat or per-client licensing costs — every instance is AGPL-licensed.

Training & research

A training provider running a cybersecurity engineering course uses CRANE to teach students how CRA compliance works in practice — not just in theory.

With CRANE, they:

  • Spin up a shared instance for the class in minutes — students get individual accounts with scoped roles.
  • Have each student team register a fictional product and work through the full lifecycle: SBOM, risk assessment, vulnerability handling, release gate.
  • Use the audit log to review every action taken by each team — traceable, timestamped, tamper-evident.
  • Let researchers use CRANE as a live reference implementation of CRA Article 3, Annex I and Annex II obligations.
  • Run it all free and open source — no licensing barriers for training use.
